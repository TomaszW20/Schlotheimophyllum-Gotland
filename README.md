# Schlotheimophyllum-Gotland
Digital paleontological repository of the rugose coral Schlotheimophyllum patellatum (Schlotheim, 1820) from the Silurian of Gotland, Sweden. Open access dataset of 225 high-resolution scans of thin sections and acetate peels, supporting the publication by Wrzołek &amp; Zatoń 2023. Hosted by University of Silesia in Katowice. Licenced under CC BY 4.0.
